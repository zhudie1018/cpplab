# C++ 练习台

一个单文件的 C++ 在线练习站：**10 章 / 33 节 / 55 道题**，每节都有「常用函数讲解 + 标准写法 + 练习题」，写完点判题自动跑测试点。

## 直接用

打开 <https://你的用户名.github.io/cpplab/> （部署后替换成你的地址）。

## 功能

- 按章节系统学习：入门基础 → 流程控制 → 函数 → 数组与字符串 → 指针与引用 → 结构体与枚举 → 类与对象 → 继承与多态 → STL → 文件与异常
- 每节三件套：常用函数讲解、标准写法（一键载入编辑器）、练习题（2~3 个测试点 + 提示 + 难度）
- 自动判题：逐个测试点对比输出
- AI 出题：按当前小节现场生成新题，AI 同时给参考解法，页面自动验证测试点

## AI 出题怎么配

点右上角 **⚙ 设置**，填自己的 API Key（默认 DeepSeek，兼容任何 OpenAI 风格接口）。

Key 存在浏览器 localStorage，**不会上传到任何服务器，也不会写进源码**。

## 判题

编译运行使用 [Judge0](https://judge0.com) 的公共实例，有频率限制（约每分钟 20 次）。长期公开使用建议自建 Judge0，改页面里的 `JUDGE0` 常量即可。
